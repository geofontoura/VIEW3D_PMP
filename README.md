# VIEW3D_PMP

Modelo 3D interativo do PMP (Criciúma/SC): topografia real, 7 formações sedimentares, 3 sills e furos de sondagem.

- **Cor:** Hipsometria / Geologia real (CPRM) / Satélite (Esri World Imagery)
- **Camadas:** Sólido ON/OFF, Topografia ON/OFF, Furos ON/OFF (colunas 3D coloridas pelas unidades atravessadas)
- **Corte** em 4 direções (Leste→Oeste, Oeste→Leste, Norte→Sul, Sul→Norte) com slider e animação
- Opacidade, exagero vertical e tema escuro/claro; legenda clicável
